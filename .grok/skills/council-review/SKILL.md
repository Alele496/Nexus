# Council Review — 三维并行代码审查

同时从三个维度审查代码，汇总为综合报告。

## 执行流程

1. **并行启动 3 个 reviewer**（全部使用 background=true）：
   - reviewer (安全维度)：注入风险、权限漏洞、数据暴露
   - reviewer (性能维度)：算法复杂度、冗余 I/O、缓存
   - reviewer (可读性维度)：命名、结构、风格一致性

2. **等待全部完成**后汇总

3. **综合裁决**：
   - 全部 PASS → 审查通过
   - 任一 FAIL → 列出问题，要求修复
   - 发现根本性偏差 → ESCALATE，需用户介入

## Prompt 模板

### 安全 Reviewer Prompt
```
从安全角度审查以下代码改动：
- 注入风险（SQL/命令/XSS/路径遍历）
- 权限漏洞（认证/授权/敏感数据）
- 依赖安全（已知漏洞）
- 数据保护（明文存储/日志泄露）

原始需求：<需求描述>

输出格式：PASS/FAIL + 具体问题列表。
```

### 性能 Reviewer Prompt
```
从性能角度审查以下代码改动：
- 算法复杂度（时间/空间）
- I/O 效率（冗余读写/批量操作）
- 数据库（N+1查询/索引/事务）
- 内存（不必要的分配/泄漏风险）

原始需求：<需求描述>

输出格式：PASS/FAIL + 具体问题列表。
```

### 可读性 Reviewer Prompt
```
从可读性角度审查以下代码改动：
- 命名清晰度
- 函数长度和嵌套深度
- 注释质量和准确性
- 与项目风格的一致性

原始需求：<需求描述>

输出格式：PASS/FAIL + 具体问题列表。
```

## 汇总格式

```
## Council 审查报告

### 安全审查
<安全 reviewer 的输出>

### 性能审查
<性能 reviewer 的输出>

### 可读性审查
<可读性 reviewer 的输出>

### 综合裁决
PASS/FAIL/ESCALATE — <三句话总结>
```
